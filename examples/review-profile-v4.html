Six questions for a fair review

1. Do the calculations reproduce?

The attachment contains dated relative returns and versioned rules to reproduce the metrics. Raw account values and flows are private, so their conversion into returns cannot be reproduced from this package alone.

2. Are signatures and history valid?

The exporter checked every signed event against this profile key. Run your own check. Earlier publication has not been checked; retain a previous copy or independently obtained checkpoint for comparison.

3. Where did the data come from?

Manual observations or a user-supplied export, as declared per record. Parsing and file hashes do not establish provider authenticity.

4. Who controls the signing key?

The key identifies a signing capability, not a person. Compare the key code through a channel you already trust and establish the applicant's identity separately.

5. What independent time evidence exists?

None is included. Period dates describe observations; neither a valid signature nor a pasted checkpoint proves when a record was created or published.

6. What coverage is missing?

No gaps between the disclosed periods were found. Omitted accounts, observations and trades cannot be discovered here. Sampled drawdown misses losses between observations.

Check and retain

  1. Open your independently obtained N170 Verify application and choose employer review.
  2. Select this HTML file. It reads only the evidence attachment and recomputes every record.
  3. Compare a key code obtained through a trusted channel. Select your previous copy to detect truncation, replacement or conflicting histories.
  4. Ask the owner about the account scope, missing dates, cash-flow treatment and source authenticity. A technically consistent record can still contain false inputs.
